# Agent 条件追踪规范

## 范围

本规范约束 Assistant Agent 模式中的条件追踪（Watch）：用户委托系统在内容或讨论发生变化
时记录命中，并在助手内投递。Watch 不是通用赞/评/关通知中心，也不是推送产品。授权、工具
白名单与预算由 [SPEC-assistant-agent-mode](SPEC-assistant-agent-mode.md) 约束。命中内容
若进入回答，社区事实证据仍由 [SPEC-grounded-assistant](SPEC-grounded-assistant.md) 约束。

## 任务与条件

- `WCH-001`：Watch 是绑定当前用户的条件任务，必须包含稳定标识、条件类型、目标（作者、
  标签、关键词或帖子）以及启用状态。用户可以列出、创建、修改、停用和删除自己的任务。
- `WCH-002`：第一版允许的纯规则条件仅有：`author_new_post`（指定作者发布新帖）、
  `tag_new_post`（指定标签下出现新的已发布帖子）、`keyword_new_post`（新发布帖子标题或
  正文匹配关键词）、`post_revised`（指定已发布帖子发生内容修订）。
- `WCH-003`：第一版允许的语义条件仅有 `discussion_spike`（指定帖子或话题的讨论量明显
  上升）。该条件必须先用行为或计数字段做规则预筛选；只有通过预筛选的候选才允许使用模型
  判定是否构成一次命中。禁止对全部 Watch 任务定时调用模型。
- `WCH-004`：未发布、取消发布、删除或当前用户不可见的帖子不得产生命中。作者或标签目标
  不存在时，创建任务必须失败并说明原因，不得创建永远无法命中却报告成功的任务。
- `WCH-005`：同一用户对同一条件类型与同一目标不得存在两条同时启用的重复任务；重复创建
  必须返回已有任务或明确的冲突错误，不得默默生成重复命中流。

## 匹配与执行

- `WCH-010`：规则条件由内容或行为事件驱动匹配，不得以固定间隔询问模型“有没有更新”。
- `WCH-011`：每次匹配尝试留下执行记录：任务标识、事件标识或等价去重键、是否命中、是否
  调用了模型判定、最终状态。同一事件对同一任务重试不得产生重复未读命中。
- `WCH-012`：`discussion_spike` 的预筛选阈值可配置，但必须在未达阈值时直接结束且不调用
  模型。模型判定失败时该次尝试记为失败或跳过，不得改写成规则命中。
- `WCH-013`：匹配与投递失败不得影响帖子发布、评论或推荐主路径。

## 投递

- `WCH-020`：命中只写入该用户的助手 Watch 收件箱，并允许在该用户下一次 Agent 对话的
  上下文中注入未读摘要。不得因此创建私信、不得写入赞/评/关通知中心、不得发送推送。
- `WCH-021`：用户可以列出命中、标记已读。列表只返回该用户自己的命中；命中中的帖子条目
  必须在返回前按当前可见性过滤，不可见目标删除标题与片段并标记不可用。
- `WCH-022`：命中不是社区证据。Agent 若根据命中发表关于社区内容的事实陈述，仍须按
  `ASST-002`～`ASST-012` 回源并引用。

## 工具与确认

- `WCH-030`：工具 `create_watch_task`、`list_watch_tasks`、`update_watch_task`、
  `delete_watch_task` 只作用于当前用户，并遵守本规范的条件集合与去重规则。
- `WCH-031`：创建、修改、删除 Watch 不走 `delete_post` 的逐次确认。删除立即停止后续命中；
  已经产生的命中保留直到用户删除或按保留策略过期。
- `WCH-032`：对外提供任务与命中的认证接口；越权访问其它用户的任务或命中必须拒绝。

## 失败与兼容

- `WCH-040`：Watch 存储或匹配器不可用时，创建/列表接口返回暂时不可用；已经接受的任务在
  恢复前可以漏匹配，恢复后不得用补扫把过期不可见内容补成新命中。
- `WCH-041`：未知条件类型必须拒绝创建，不得降级成其它条件或静默忽略。
- `WCH-042`：Watch 命中可以作为聊天流中的独立事件类型投递；旧客户端必须忽略无法识别的
  事件，不得将其解释为帖子来源（延伸 `ASST-040` / `AGNT-060`）。

## 验收标准

- `WCH-A01`：覆盖四种规则条件的成功命中，以及目标不可见/未发布时不命中。
- `WCH-A02`：覆盖重复任务冲突、越权读写拒绝、未知条件类型拒绝。
- `WCH-A03`：覆盖 `discussion_spike`：未过预筛选不调用模型；过预筛选后模型否定则不命中。
- `WCH-A04`：覆盖命中只出现在本人收件箱与下次对话摘要，不写入私信；同一事件不重复未读。
- `WCH-A05`：覆盖停用或删除任务后不再产生新命中，以及匹配失败不影响发帖主路径。
