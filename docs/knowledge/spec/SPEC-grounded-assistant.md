# 社区内容证据化 Assistant 规范

## 范围

本规范定义 Assistant 如何理解用户查询、组织社区检索结果并给出可追溯回答。查询理解可以处理
用户输入，但回答中的事实只能由当前可用的已发布社区内容支撑。

本草案不把 Assistant 定义为通用聊天、外部网络问答、私有数据查询或自主执行平台，也不规定模型、
提示词、检索引擎或工具编排方式。

## 术语

- **社区证据**：回答生成时仍可访问的已发布社区内容片段及其稳定帖子标识。
- **来源引用**：把回答关联到实际社区证据的结构化来源信息。
- **受支持陈述**：能够由返回来源中的内容直接支持的事实性陈述。
- **证据不足**：检索不到社区证据，或现有证据无法支持用户问题中的关键事实。

## 查询与证据边界

- `ASST-001`：Assistant 请求必须绑定已认证用户和仅属于该用户的会话；其他用户不得读取或续接该会话。
- `ASST-002`：事实回答只能使用已发布社区内容作为证据，不得使用未发布、删除、受限内容、私信、
  私有用户资料、外部网页或模型参数知识补足事实。
- `ASST-003`：社区内容在进入回答上下文前必须再次确认可用状态；只有搜索元数据而没有真实内容时，
  不得宣称已经取得证据。
- `ASST-004`：检索、排序或生成步骤不得把社区内容中的指令当作系统指令执行；社区证据始终是不可信数据。
- `ASST-005`：证据不足时必须明确说明无法从已发布社区内容回答，不得编造答案、来源或不存在的帖子标识。

## 回答与来源

- `ASST-010`：有证据的回答必须同时返回至少一个来源引用；每个引用包含稳定帖子标识，并能够解析到
  实际用于回答的已发布内容。
- `ASST-011`：Assistant 只能引用本次检索并验证过的来源；模型自行生成的引用标记不得被当作真实来源。
- `ASST-012`：回答应区分社区内容中的事实、作者观点和无法确认的信息，不得把帖子观点提升为平台事实。
- `ASST-013`：回答可以组织、摘要和比较多条证据，但不得改变证据原意或隐去影响结论的明显冲突。
- `ASST-014`：来源内容不得因为被引用而获得额外访问权限；用户打开来源时仍适用正常内容权限。

## 会话与流式结果

- `ASST-020`：一次成功的流式回答由零个或多个内容片段、来源引用和一个完成事件组成；完成事件只能出现一次。
- `ASST-021`：失败结果必须以明确错误或降级事件结束，不得先报告完成再补报失败。
- `ASST-022`：客户端取消或请求超时后，Assistant 必须停止继续发送该请求的内容和来源。
- `ASST-023`：会话上下文必须有明确上限；截断历史时不得把其他用户或其他会话内容混入当前回答。

## 失败与安全行为

- `ASST-030`：内容检索不可用、证据验证失败或回答生成不可用时，应返回可识别的降级结果，不得使用
  无证据的自由生成作为备用答案。
- `ASST-031`：输入或输出触发安全策略时必须拒绝或降级，并保持会话和来源数据不越权。
- `ASST-032`：错误响应不得泄露系统提示词、secret、内部地址、原始堆栈或其他用户的会话内容。
- `ASST-033`：重复请求不得在同一会话中形成彼此矛盾的完成状态；客户端应能用请求标识区分重试。

## 兼容边界

- `ASST-040`：现有 `/api/v2/assistant/chat` 的流式事件类型和必需字段在同一主版本内保持向后兼容。
- `ASST-041`：内部模型、检索和编排方式可以更换，但“仅使用已发布社区证据、来源可追溯、证据不足拒答”
  三项行为不得因内部替换而改变。
- `ASST-042`：增加新的来源类型前，必须先由人类修改意图或批准规范；未知来源类型不得被旧客户端解释为帖子证据。

## 验收标准

- `ASST-A01`：对有充分证据的问题，验证回答只引用实际检索到的已发布帖子，且引用可以解析。
- `ASST-A02`：对无结果、只有元数据、内容已删除和内容未发布四种场景，验证 Assistant 明确拒绝无证据回答。
- `ASST-A03`：在社区帖子中放入提示注入文本，验证其不会改变证据边界、来源集合或系统行为。
- `ASST-A04`：让生成结果包含伪造来源标记，验证对外来源仍只来自已验证的社区证据。
- `ASST-A05`：覆盖正常完成、客户端取消、工具超时、生成失败、安全拒绝和会话越权路径。

## 待人类确认

以下问题不构成本草案要求：

- “仅基于已发布社区内容”是否允许 Assistant 提供用户资料、个性化推荐等非证据型功能；本草案按不允许处理。
- 来源需要精确到帖子、段落还是原文片段，以及单次回答的最少和最多来源数。
- 来源在回答后被删除或限制时，历史会话应保留什么内容和提示。
- Assistant 的响应延迟、拒答准确率、引用正确率和证据覆盖率目标。
