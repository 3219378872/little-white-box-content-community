# 小白盒内容社区后端

## 目标与优先级

内容社区是产品主体。用户能够创作、发布、讨论、收藏和交流，并独立地通过关注流、普通搜索与
推荐发现可访问的帖子。社区核心能力和发现入口不以使用 Agent 为前提。本轮不定义首要用户群体。

小白盒 Agent 是辅助用户使用社区的工具，不是独立通用聊天或长期陪伴产品。它处理需要澄清条件、
多轮检索、比较和综合的复杂需求，帮助用户找到、理解和使用资料，交付回应实际条件的自然语言回答。

Agent 优先使用社区资料；不足时尝试已授权的互联网检索，并如实说明社区缺口、故障和结论限制。
普通对话可以自然进行，不强制检索。基于资料的实质性信息必须有对应依据，不能编造偏好、资料或确定性。

## 成功标准

- 用户能够预测内容状态、权限、可见性与操作结果；失败不伪装成功，重试不制造重复资源。
- 复杂需求通过结构化问答按需澄清，允许未知、无偏好、跳过和先搜索；条件足够就继续任务。
- 综合回答区分资料陈述、个人体验和推导，并将信息与具体帖子或网页关联。前端按一篇来源一张卡
  展示相关原文摘录，完整资料保持可达；卡片不代替回答，也不代替逐项证据关联。
- 已接受任务可在用户离线后继续，用户能够停止或转向；恢复不重复已经成功的操作。
- 用户控制自己的自然语言记忆、历史和条件追踪，个人上下文不是隐藏画像或公共证据。
- 质量评价关注条件理解、资料相关性、支持关系与任务解决程度，不以聊天时长、链接数量或合成评测
  冒充实际质量。

## 范围

- 注册、登录、公开资料、关注关系；帖子草稿、发布、取消发布、删除、评论、媒体、点赞与收藏。
- 一对一私信；独立的关注流、帖子/用户/标签搜索、个性化及冷启动推荐。
- 消息页中固定的小白盒 Agent 虚拟线程、持久任务、结构化澄清、社区优先检索、外部补充与可信引用。
- 授权范围内的本人帖子操作、推荐、自然语言 MEMORY/USER、本人 Assistant 历史与 Watch 条件追踪。
- 永久前台对话、历史清除、离线恢复、停止、转向、排队与上下文维护。
- 行为反馈、关闭个性化、隐私保留、健康与质量观测。

## 非目标

- 管理后台、账户注销、申诉或内容审核工作流。
- 群聊、普通私信撤回/删除、赞评关通知中心或系统推送。
- 把 Agent 作为机器人用户，或混入普通用户私信的数据边界。
- Agent 自动评论、自动私信、自动购买、访问未授权数据，或允许用户修改平台人格和安全规则。
- 检索普通私信、账户 secret、未发布内容或他人的个人记忆；建立跨会话匿名画像或自动合并匿名历史。
- 强制普通闲聊逐句引用；把模型生成的链接当成可信资料；在依据不足时保证给出确定答案。
- 未达正式质量门槛即宣传学习排序改善。
