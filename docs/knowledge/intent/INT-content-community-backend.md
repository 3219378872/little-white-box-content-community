# 小白盒内容社区后端

本仓库为小白盒内容社区提供后端能力。

## 目标

已认证用户能够创建、发布、互动和一对一交流；任何人都能按权限阅读已发布内容，并通过
关注流、搜索和个性化推荐发现相关帖子。Assistant 基于已发布社区内容理解查询并给出
可追溯回答；在用户显式授权进入 Agent 模式后，Assistant 以该用户身份调用受控工具，
完成内容搜索综述、结构化记忆、可解释推荐、条件追踪，以及本人帖子的创建、更新与删除。
系统用行为数据闭环、可观测性和故障降级支撑发现质量与服务可靠性。

## 成功标准

- 内容生命周期、权限和可见性对调用者可预测：草稿仅作者可见，已发布内容匿名可读，
  取消发布或删除后不再出现在普通读取、发现或 Assistant 证据中。
- 写操作可区分未认证、无权限、不存在、参数错误、版本冲突、幂等冲突和暂时不可用；
  权威写入未确认不得报成功，异步派生效果失败不得诱导重复写入。
- 关注流、搜索和推荐只返回当前访问者可见的已发布内容；关注流不混入推荐；个性化
  故障时可以规则降级，可见性无法验证时必须失败关闭。
- Assistant 事实回答必须带来源；证据不足必须拒答；不得用私信、账户资料、未发布内容或
  模型参数知识补足事实。社区证据限于仍可访问的已发布帖子，以及附着在这些帖子上的有效评论。
- Agent 模式仅在用户显式授权后可用，始终以该用户身份行动且权限不超过其本人；高危写
  操作逐次向用户确认，工具调用受分组白名单与执行预算约束，且可审计、可拒绝。
- Agent 记忆是用户可见、可修改、可删除的结构化偏好与任务，不是不可见的黑盒档案；写入
  必须经过校验与冲突处理，不得把未确认的模型猜测当成已确认偏好。
- Agent 推荐的候选必须来自现有推荐/检索系统并回源验证，不得由模型凭空列出帖子标识；
  解释不得把作者观点说成平台事实。
- Agent 条件追踪由内容或行为事件匹配触发，不得靠定时调用模型空转；命中只进入该用户的
  助手收件箱与下次对话上下文，不构成赞/评/关通知中心或推送产品。
- 行为事件可逐项接受或拒绝、可去重、可按请求归因；关闭个性化后停止用于画像并在
  时限内清除在线特征。
- 搜索与 Assistant 的正式质量门禁、以及月度 SLO 报告，必须建立在人类评审的冻结集
  和真实生产观测上，合成数据只能验证工具，不能关闭门禁。

## 范围

当前产品范围仅包括：

- 注册、登录、资料维护和一对一关注关系。
- 帖子草稿/发布/取消发布/删除、评论、图片媒体、点赞、收藏。
- 一对一私信（文本与已上传媒体）。
- 关注流、综合搜索（帖子/用户/标签）和个性化或冷启动推荐。
- 基于已发布帖子与其有效评论的证据化 Assistant（enhanced_search 模式）。
- Assistant Agent 模式：经用户授权后以其身份执行分组白名单内的工具，包括站内内容
  搜索综述、网络检索（仅研究素材）、本人帖子创建/更新/删除、结构化记忆读写、基于
  现有推荐系统的可解释推荐、以及针对作者/标签/关键词/帖子修订/讨论量的条件追踪。
  图片只能引用本会话上传的媒体。
- 助手作用域内的记忆列表与编辑、Watch 任务与命中列表、推荐反馈、结构化聊天卡片。
- 客户端行为接收、保留期限、关闭个性化、健康检查与 SLO 口径。

## 非目标

以下能力明确不在当前意图内，未批准新规范前不得作为对外承诺：

- 账户注销、申诉、管理后台、内容审核工作流。
- 群聊、消息撤回、消息删除、已读回执以外的消息能力。
- 点赞、评论、关注的站内通知中心或推送产品（私信权威写入本身除外）。助手作用域内的
  Watch 命中列表与下次对话注入不属于该通知产品。
- 通用聊天、账户资料查询、游戏库/价格/商城，以及自动评论、自动私信、自动购买。
- 不受用户授权、工具白名单和执行预算约束的通用外部网页问答或自主平台操作；受限的
  Agent 形态以 `SPEC-assistant-agent-mode`、`SPEC-agent-memory` 与 `SPEC-agent-watch`
  为准，未按其批准扩张前不得对外承诺更多。
- 跨会话匿名画像，以及登录后自动合并匿名历史。
- 学习排序效果宣传（未达到曝光与身份门槛前）。

## 约束

- “应该做什么”只由本意图和引用它的已批准规范决定；技术方案、服务拆分和存储选型
  不属于本层。
- 破坏已发布契约必须使用新版本，或先修改并重新批准对应规范。
- 正式评测与 SLO 门禁不得用伪造标注或伪造生产观测关闭。
