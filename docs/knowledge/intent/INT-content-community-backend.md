# 小白盒内容社区后端

本仓库为小白盒内容社区提供后端能力。

## 目标

已认证用户能够创建、发布、互动和一对一交流；任何人都能按权限阅读已发布内容，并通过
关注流、搜索和个性化推荐发现相关帖子。Assistant 仅基于已发布社区帖子理解查询并给出
可追溯回答。系统用行为数据闭环、可观测性和故障降级支撑发现质量与服务可靠性。

## 成功标准

- 内容生命周期、权限和可见性对调用者可预测：草稿仅作者可见，已发布内容匿名可读，
  取消发布或删除后不再出现在普通读取、发现或 Assistant 证据中。
- 写操作可区分未认证、无权限、不存在、参数错误、版本冲突、幂等冲突和暂时不可用；
  权威写入未确认不得报成功，异步派生效果失败不得诱导重复写入。
- 关注流、搜索和推荐只返回当前访问者可见的已发布内容；关注流不混入推荐；个性化
  故障时可以规则降级，可见性无法验证时必须失败关闭。
- Assistant 事实回答必须带来源；证据不足必须拒答；不得用私信、资料、未发布内容或
  模型参数知识补足事实。
- 行为事件可逐项接受或拒绝、可去重、可按请求归因；关闭个性化后停止用于画像并在
  时限内清除在线特征。
- 搜索与 Assistant 的正式质量门禁、以及月度 SLO 报告，必须建立在人类评审的冻结集
  和真实生产观测上，合成数据只能验证工具，不能关闭门禁。

## 范围

当前产品范围仅包括：

- 注册、登录、资料维护和一对一关注关系。
- 帖子草稿/发布/取消发布/删除、评论、图片媒体、点赞、收藏。
- 一对一私信（文本与已上传媒体）。
- 关注流、综合搜索（帖子/用户/标签）和个性化或冷启动推荐。
- 基于已发布帖子的证据化 Assistant。
- 客户端行为接收、保留期限、关闭个性化、健康检查与 SLO 口径。

## 非目标

以下能力明确不在当前意图内，未批准新规范前不得作为对外承诺：

- 账户注销、申诉、管理后台、内容审核工作流。
- 群聊、消息撤回、消息删除、已读回执以外的消息能力。
- 点赞、评论、关注的站内通知中心或推送产品（私信权威写入本身除外）。
- 通用聊天、外部网页问答、私有资料查询、自主执行平台操作。
- 跨会话匿名画像，以及登录后自动合并匿名历史。
- 学习排序效果宣传（未达到曝光与身份门槛前）。

## 约束

- “应该做什么”只由本意图和引用它的已批准规范决定；技术方案、服务拆分和存储选型
  不属于本层。
- 破坏已发布契约必须使用新版本，或先修改并重新批准对应规范。
- 正式评测与 SLO 门禁不得用伪造标注或伪造生产观测关闭。
